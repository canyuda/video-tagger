## 3. 环境与凭据（只有路径，没有值）

- **`video-analysis-app/.env.local`**（权限 600，git 已忽略）：`DASHSCOPE_API_KEY`（百炼：VLM/ASR/embedding）、`TYPESAFE_API_KEY`（Jev，主源 `~/.agentguardrc`，此处为镜像）、`ZHIPU_API_KEY`、`ARK_API_KEY`（火山，备选）、`OSS_*`（**默认不启用**，D46：现指向团队测试桶，勿写）、`DOUYIN_COOKIE`（完整登录态）。字段说明见 `.env.example`。
- **CLI 读取顺序**：环境变量 → `.env.local`（缺失即启动报错，fail fast）。见 docs/04 §4。
- **双机注意**：开发在家庭 Mac、Windows 真机验证在公司机。**公司机上没有 `.env.local` 也没有 `~/.agentguardrc`**——需手动安全同步（加密渠道），绝不通过 git/网盘明文同步。
- **安全事项**：调研会话的对话记录中出现过全部 key 明文（会话历史可能被同步），建议对敏感度最高的 DOUYIN_COOKIE 与 OSS AK/SK 做一次轮换；OSS 建议将来开个人桶。
- **开工冒烟（第一件事）**：四把 key 各发一个最小请求验证有效（百炼一次 flash 对话、Jev 一个最小 Choice、智谱一次对话、火山可选）——避免开工半天才发现某把 key 未开通。
