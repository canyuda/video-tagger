# 01 · 需求与竞品分析

> 背景调研时间：2026-10-02。本文档回答"做什么、不做什么"，供后续阶段直接引用。

## 1. 背景

用户观察到两类已成熟的"视频内容分析"产品：

- **钉钉会议 AI 听记**：对视频会议中的**声音 + 共享桌面画面**做理解，生成 AI 纪要、观点树、章节、待办事项。场景是实时/录制的会议，音画同源，说话人明确。
- **抖音评论区 @豆包 / @抖音求真**：在平台内对单条短视频触发 AI 分析（内容总结、事实核查等）。场景是短视频，平台内嵌，用户无法自定义分析角度，结果无法沉淀。

两者本质相同：多模态内容理解（语音转写 + 画面理解）→ 结构化生成。差异在**内容来源、触发方式、可定制性、结果归属**。

## 2. 对标拆解与定位差异

| 维度 | 钉钉 AI 听记 | 抖音 @豆包/@求真 | 本产品 |
|---|---|---|---|
| 内容来源 | 会议音视频（自家生态） | 平台内视频 | **本地文件 + 抖音 +（后续）B站等** |
| 音频理解 | ✅ 核心 | ✅（平台自有） | ✅ 云端 ASR |
| 画面理解 | ✅ 共享屏幕 | ✅ | ✅ 关键帧/视频直传 |
| 自定义提示词 | ❌ | ❌ | ✅ **核心卖点** |
| 报告结构 | 固定（纪要/观点树/章节/待办） | 固定 | 固定骨架 + 模板扩展 |
| 结果沉淀/导出 | 生态内 | 评论区，不可导出 | 本地 SQLite + Markdown 导出 |
| 平台 | 全端 | App 内 | **Windows + macOS 桌面** |

**定位**：面向个人的视频内容工具，两阶段交付——**V1 视频分类工具**（批量导入 → 自动打类型标签 → 筛选/统计，解决"下载多了没法管"的素材整理问题），**V2 内容分析**（在分类库之上生成可配置、可复用、可沉淀的结构化报告）。不做实时会议（那是钉钉的主场），做"事后处理"。

## 3. 用户与场景

- 素材整理（V1）：批量下载/积攒的视频自动分类打标，按类型筛选、统计、掌握构成，为后续分析圈定范围。
- 内容研究（V2）：看大量口播/科普/带货视频，需要观点提炼与跨视频对比的素材库。
- 学习整理：教程/录屏视频转知识点、章节、待办。
- 二创/写作：从视频提取金句、脚本结构、话术。
- 求真核查：对说法存疑的视频提取论断清单（模板层能力）。

## 4. V1 范围（MoSCoW）

### Must（V1 分类版）
- 本地视频导入（拖拽 / 多选 / 批量）
- 抖音链接导入（Phase 2 接入，复用已验证的下载能力，见文档 04 §5；元数据随下载带入作分类证据）
- 自动分类（感知 + 决策两层）：元数据 + 10 抽样帧（低置信补音频样本转写）→ flash 档 VLM 感知（中英桥接，输出英文观察与中文证据摘要）→ **Jev（typesafe.ai System One）** 决策，输出类型/概率分布/置信度（文档 03 §3.0）
- 分类体系（taxonomy）可配置：增删类型、有价值标记、特征 hint、恢复默认
- 任务库：缩略图网格、类型标签、按类型/来源/有价值筛选、类型分布统计；分类结果 **CSV 导出**（勾选/当前筛选全量，字段见文档 06 §4）
- 任务队列：阶段化进度、失败按阶段重试、用户主动取消（cancelled 终态，已完成阶段缓存保留）
- 首启引导 Onboarding（key 检测→配置向导→放行导入）；批量任务托盘后台运行 + 完成通知
- 设置：模型/API Key（VLM 与 ASR）、分类参数（帧数/置信度阈值）

### Must（V2 分析版，前置条件：V1 期间分析 spike 质量结论达标）
- 混合分析管线：云端 ASR 转写 + 关键帧 + 云端多模态模型（详见文档 03）
- 分析时长上限 20 分钟（导入即拒；V1 分类不限时长）
- 门控 fail-open：无价值类型默认跳过分析（no_value 状态，可改判强制分析）
- 自定义提示词模板（编辑 + 保存 + 分析时选择）
- 结构化报告：摘要 / 观点树 / 章节（带时间锚点）/ 待办 / 金句；查看与导出 Markdown
- 缓存复用：换提示词/模型重新分析不重跑转写与抽帧

### Could（按需排优先级）
- 按类型归档/移动文件目录（V2 再议：自动移动用户文件，需在分类准确率被证实后开）
- 剪贴板链接自动检测（V1.5：复制抖音链接后回 App 自动提示导入）
- 报告时间锚点 → 播放器 seek；多模型切换对比
- B 站等更多站点（yt-dlp 生态）；说话人分离；视频直传 API 路线；垂直模板库；报告对比/素材库检索

### 非目标（明确不做）
- 实时会议录制与转写（架构上不阻断，管线阶段化即可复用）
- 移动端
- 视频剪辑/生成
- 自动更新（前期手动下载新版本）
- 本地/离线模型运行（已决定全云端，离线不可用）
- 长视频（>20 分钟）分析：会议录像等场景，待后续按需设计分段方案（扩展预留见文档 03 §5）
