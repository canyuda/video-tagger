## 卡点的"最早暴露时点"设计

以上风险都已绑定到阶段验收标准（文档 02），确保最危险的尽早暴露：

- **分类准确率（V1 核心风险 13）** → V1 Phase 0 验收线 top-1 ≥90%
- 风险 2/8（分析质量/结构化输出）→ V1 期间的分析 spike 先探路，V2 Phase 3 验收线（≥80% 可直接采用、JSON 成功率 ≥95%）
- 风险 3/5（无解说/字幕直读）→ V1 分类评测集 + V2 spike 样本覆盖
- 风险 1 → V1 Phase 2 验收（10 链接 ≥9 成功），且架构上永远不阻塞本地链路
- 风险 9 → V1 Phase 1 第一周就出双平台空白安装包（先跑通打包链，再填功能）

## 非技术风险

- **版权与使用边界**：下载与分析仅限个人研究使用；应用不做内容二次分发；对外发布时文案明示"用户自担内容合规责任"。
- **API 合规**：各厂商对"上传第三方视频内容"的条款需在接入前核对（尤其是把抖音视频帧与音频发给百炼/方舟——豆包与抖音同属字节，条款上反而更顺；仍以各自服务条款为准）。
